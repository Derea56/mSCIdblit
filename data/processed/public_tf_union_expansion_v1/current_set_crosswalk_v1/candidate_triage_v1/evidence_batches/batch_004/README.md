# Public TF evidence collection batch_004

This is a bounded exact-pair literature-search queue derived from database-attributed TFLink regulon sets. TFLink membership is retained as a search lead only. Every row requires independent review of the exact regulator, target, species, cell/model, assay, direction, and any upstream relay. Target-cell presence and downstream activation remain separate fields. No canonical TF, regulon, or Module 22B evidence record is modified by this batch.

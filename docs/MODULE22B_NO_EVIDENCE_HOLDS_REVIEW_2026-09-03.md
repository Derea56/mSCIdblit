current Module 22B edge and evidence registers, the public TF curation queue,
and the register-backed target-gene materialization stage.

The row-complete audit is generated by
`scripts/audit_module22b_no_evidence_holds.py` and is written to the ignored

## Result

All 4,957 Module 22A handoff rows with `edge_status=no_evidence_boundary` and
`confidence_tier=low` were reviewed. Every row has linked bounded evidence in
the evidence register, but the evidence is an absence/boundary record for the
submitted upstream-to-target claim; it is not a global negative-literature
search.

| disposition | rows | meaning |
| --- | ---: | --- |
| retain no-evidence boundary | 4,812 | neither a structured terminal TF nor a recognizable TF mention in the relation text |
| manual relation-text TF resolution | 51 | a possible TF is mentioned only in narrative relation text; terminal assignment still requires review |
| review separate TF-regulon lane | 49 | one named TF is present, but no target gene is established |
| manual composite/family decomposition | 45 | a TF family or composite label is present, but no target gene is established |

All 4,957 rows still have no target gene assigned in the structured
`target_entity` field: 4,866 are `none_identified` and 91 are `null`. The
classification above is about whether a possible TF endpoint is named; it does
not change the absence of a target gene. Fifty-one of the 4,863 rows whose
structured `source_entity` is `none_identified` mention a possible TF in the
free-text relation description. Those are manual leads, not terminal TF
assignments.

Seventeen hold rows overlap an existing target-gene lane in the current stage
and signed queue. This overlap does not promote the hold: a generic TF→target
assertion does not establish that the particular Module 22A ligand/receptor
route activated that TF, and the hold itself contains no target gene to export.

Therefore the hold audit itself made zero upgrades to the held handoff rows. The
appropriate next work is a separately scoped regulon curation pass for the
named TFs and a manual decomposition pass for composite/family labels. The
4,812 rows without any recognizable TF mention cannot be promoted to a
TF→target edge without new pair-specific evidence and a defined terminal
target; the 51 narrative-text TF leads require terminal assignment first.

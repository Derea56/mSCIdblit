# mSCIdblit v1.9.41

## Mechanism graph release

This release adds ten selectively curated primary-literature expansions to the Module 21B mechanism graph. The batch covers CD300F–SHP1, SIGLEC7–SHP1, SIGLEC7–SHP2, SIGLEC9–SHP1, SIGLEC9–SHP2, PVRIG–SHIP1, Dectin-1–SYK, Dectin-1–PKCδ, STAB1–GULP1, and STAB2–GULP1 routes.

All ten routes include source-supported receptor-proximal intracellular continuations. The entries preserve receptor-proximal motif, adaptor, phosphatase, kinase, and efferocytosis or activation-readout context from the source evidence. All routes remain evidence-only; no causal graph edge, confidence score, transcription factor, or target-gene endpoint is created.

The release contains 10 new literature-expansion rows and increases the materialized route-evidence table from 17,131 to 17,141 rows. The underlying mechanism graph topology is unchanged at 11,952 nodes and 14,722 edges. The evidence layer now contains 1,094 selective literature-expansion routes and remains available to mSCS for route plausibility evaluation.

Primary locators represented in this batch include PMCID:PMC4151829, PMID:15557178, PMCID:PMC4749091, PMID:15845454, PMCID:PMC3157896, PMID:20599701, DOI:10.1242/jcs.049569, and PMID:18230608.

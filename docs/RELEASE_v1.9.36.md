# mSCIdblit v1.9.36

This release adds the one-hundred-thirty-first selective primary-literature expansion batch for Module 21B signaling-route evidence.

The evidence layer adds ten P1 annotations:

- Alpha5beta1-CD97 and alphaVbeta3-CD97 endothelial attachment/function.
- SS4-negative neurexin-1-ADGRL1 transsynaptic adhesion.
- Clusterin-ApoER2 and clusterin-VLDLR uptake, Dab1-associated signaling, and SVZ output.
- HGF-MET-GAB1 receptor-proximal signaling.
- GDNF-GFRA1:RET-PLCG1 signaling.
- Tie2-pY1101-PI3K, Tie2-GRB2, and Tie2-GRB7 docking branches.

The five adaptor-branch routes retain mapped intracellular evidence but leave transcription-factor and target-gene layers unresolved. The remaining annotations retain ligand-to-output evidence without inventing intracellular links. All routes remain evidence-only for mSCS plausibility analysis; no causal graph edges or database confidence scores are created. The release contains 17,091 signaling-route evidence records and 1,044 cumulative literature-expansion rows.

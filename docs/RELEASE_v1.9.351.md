# mSCIdblit release v1.9.351

This release adds a primary-literature dopamine→D1-like receptor→PKA→CREB→BDNF
promoter IV route. The route composes dopamine/D1-like receptor signaling,
PKA-CREB activation and BDNF promoter/exon-IV output evidence while preserving
the receptor-subtype and cross-reactivity limits of the primary astrocyte
study.

This is evidence-layer data only. It does not create graph edges, causal
assertions, confidence scores, or a claim that one experiment demonstrates the
complete sequence.

# mSCIdblit v1.9.143

This release adds 25 source-linked receptor-proximal interaction annotations for priority P2 neuronal evidence. The records cover GABA-A/GABA-B receptor-associated proteins, AMPA and kainate receptor complexes, calcium and potassium channel auxiliaries, nicotinic and purinergic receptor complexes, and cytoskeletal or trafficking partners. Functional output remains explicitly `unknown` where the primary evidence establishes an intermediate interaction but not a downstream readout.

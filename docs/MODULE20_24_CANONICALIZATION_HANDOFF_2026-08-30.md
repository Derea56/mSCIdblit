## Evidence axes and paper-provenance checkpoint

The next canonicalization pass added an explicit, independent evidence
grading layer. The additive migration is
`schema/module20_24_evidence_grading.sql`; it adds `evidence_grade`,
`context_level`, `grading_basis`, and `grading_status` to both
`SignalingEdgeRegisterSource` and `SignalingEdgeSource`. It does not change
`schema/schema.sql`, graph edges, or release gates.

The rubric is documented in `docs/MODULE20_24_EVIDENCE_GRADING_RUBRIC.md`:

- A–E/U describes corroborated literature, single-source primary evidence,
  source-table evidence, database/profile-only evidence, reviewed
  non-promotable evidence, and unreviewed/unresolved evidence.
- L0–L4 describes no exact-pair context, non-CNS, CNS, spinal-cord tissue, and
  spinal-cord injury context.
- Negative/bounded records remain L0 for the exact asserted relationship;
  phrases such as “no SCI model” in limitations are not treated as positive
  L4 evidence.

The staging ledger is generated by
`scripts/build_module20_24_evidence_grade_ledger.py` and currently contains
15,321 B-layer evidence records. Rule-based provisional grades are populated
from explicit register labels or an exact validated Phase-2 primary-paper
route; all other cases remain unassigned/review-required. The database was
updated only for matching existing register-source rows, with 4,484 source
rows receiving the additive grade/context fields.

Exact local PubMed XML and the resolved metadata table were then used by

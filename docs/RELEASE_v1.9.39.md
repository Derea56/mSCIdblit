# mSCIdblit v1.9.39

## Mechanism graph release

This release adds ten selectively curated primary-literature expansions to the Module 21B mechanism graph. The batch covers HGF–MET–CBL, cadherin–KLRG1–SHIP1, cadherin–KLRG1–SHP2, Cd177–PECAM1–SHP1, Cd177–PECAM1–SHP2, CD48–CD244/2B4–SAP, CD48–CD244/2B4–SHP1, CD48–CD244/2B4–SHP2, CD48–CD244/2B4–SHIP1, and SLIT3–ROBO4 receptor-complex output evidence.

Nine routes include source-supported receptor-proximal intracellular continuations. The ROBO4 batch entry is intentionally retained as a ligand–receptor functional route with intracellular continuation unassayed: its evidence supports a ROBO4–UNC5B receptor-complex interaction and vascular migration/barrier output, not an intracellular relay. All ten routes remain evidence-only; no causal graph edge, confidence score, transcription factor, or target-gene endpoint is created.

The release contains 10 new literature-expansion rows and increases the materialized route-evidence table from 17,111 to 17,121 rows. The underlying mechanism graph topology is unchanged at 11,952 nodes and 14,722 edges. The evidence layer now contains 1,074 selective literature-expansion routes and remains available to mSCS for route plausibility evaluation.

Primary locators represented in this batch include PMID:15123609, PMID:17307799, PMID:9774457, PMID:9054388, PMID:10350061, PMID:11815622, PMID:15713798, PMID:10358138, and PMID:21238923.

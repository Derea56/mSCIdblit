# Cross-module path linkage batch 08: GPCR→ERK/CREB/AP-1

This batch keeps GPCR receptor-family evidence, receptor-proximal kinase
branches, transcription-factor programs and cellular outputs as separate
layers.

## Batch result

- 4 linkage records were added.
- 2-AG→CB1/CB2→ERK/Fyn→AP-1 is retained as a composite boundary-qualified program.
- 5-HT4→CREB is linked to adult enteric neurogenesis without a single terminal target gene.
- 5-HT2A-associated CREB occupancy at Arc, Bdnf1 and Cebpb promoters is retained as promoter-level comparator evidence.
- CXCL12→CXCR4→PI3K/AKT and ERK is linked to OPC migration with terminal TF unresolved.

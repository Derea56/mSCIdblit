# Cross-module path linkage batch 04: BMP/TGF-β→SMAD

This batch keeps BMP-SMAD1/5/8/9, TGF-β-SMAD2/3, and SMAD4-complex branches
distinct. Composite and paralog-unresolved receptor labels remain intact.

## Batch result

- 6 linkage records were added.
- BMP4/7→SMAD1/5/8→astrocyte CSPG/glial-scar function is supported in spinal
  demyelination models, without a separate 22A terminal TF target.
- BMP2→SMAD1/5/8/SMAD4→ID1 is supported as a receptor-family candidate with
  direct promoter evidence.
- GDF5→BMPR1B/ACVR2A→SMAD1/5/8→SOX9-associated differentiation is retained as
  a program-level path.
- GDF11→TGFBR1/ACVR2B→SMAD2/3 has receptor and relay support, but no exact
  GDF11-specific terminal target was assigned.
- TGFB1→TGFBR1/2→SMAD2→neurocan/glial-scar function is supported, while its 20B
  LR candidate remains boundary-only.
- GDF2/BMP9→ACVRL1/ACVR2A→SMAD1/5/8→ID1/ID3 is retained as an endothelial
  program candidate, not an SCI-specific path.
- No Module 20A LR classification or frozen manifest was changed.

## Supplemental primary-literature search

Four supplemental records were added:

- BMP4/7→SMAD1/5/8→CSPG output in spinal demyelinating lesions
  (PMID 17696121).
- Direct BMP-SMAD regulation of the Id1 promoter (PMID 11729207; PMID 12296825).
- TGF-beta/Smad2-dependent astrocyte neurocan formation after cortical injury
  (PMID 20427645).

These records remain supplemental candidates and are not silently promoted into
the Module 21A or 22A registers.

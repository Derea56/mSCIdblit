# Cross-module path linkage batch 05: IFN→STAT1/STAT2

This batch separates type-I IFNAR/ISGF3 signaling, type-II IFNGR/STAT1/GAS
signaling, and type-III IFNLR antiviral signaling. STAT1/STAT2/IRF9 composite
programs are retained as composite transcriptional evidence.

## Batch result

- 5 linkage records were added.
- IFN-alpha/beta→IFNAR→STAT1/STAT2/IRF9→ISRE antiviral program is supported.
- IFN-beta→IFNAR has SCI astrocyte survival and repair evidence, but no terminal
  22A target gene was assigned.
- IFN-gamma→IFNGR→STAT1 is supported at the receptor and relay layers; the exact
  22A STAT1 target remains unresolved.
- IFN-lambda→IFNLR→IRF/ISG antiviral function is supported in human astrocytes,
  but should not be merged with type-I or type-II receptor logic.
- ISGF3 and delayed U-ISGF3 target programs are kept distinct.
- No Module 20A LR classification or frozen manifest was changed.

## Supplemental primary-literature search

Four supplemental records were added:

- ISGF3 composition and STAT1/STAT2/IRF9 binding to ISRE/GAS elements
  (PMID 11440635; PMID 9078371).
- IFN-gamma/IFNGR1/STAT1 association with GAS promoter elements
  (PMID 16785527).
- IFN-beta-induced early ISGF3 and prolonged U-ISGF3 antiviral programs
  (PMID 24065129).

These remain supplemental intake candidates and are not silently promoted into
Module 21A or 22A registers.

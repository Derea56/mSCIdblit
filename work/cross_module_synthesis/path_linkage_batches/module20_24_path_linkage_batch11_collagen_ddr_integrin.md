# Cross-module path linkage batch 11: collagen/DDR/integrin

Three collagen-I paths were linked while preserving DDR1, DDR2 and α2β1 as
distinct receptor contexts.

- COL1A1→DDR1 supports receptor and matrix-remodeling function.
- COL1A1→DDR2→JAK2/ERK supports a PEA3/AP-1-associated promoter program.
- COL1A1→α2β1 supports adhesion and actin remodeling without a terminal TF.

The PEA3/AP-1 evidence is a fibroblast comparator and is not promoted to an
SCI-specific terminal-TF assignment.

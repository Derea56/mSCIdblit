# Cross-module path linkage batch 12: neuroligin/neurexin synaptic adhesion

Four trans-synaptic neuroligin/neurexin paths were linked to synaptic
specialization or transmission outputs.

- NLGN1→NRXN1 is retained as an excitatory synaptic branch.
- NLGN1→NRXN2 is retained as a separate receptor-complex context.
- NLGN2→NRXN1 is retained as an inhibitory synaptic branch.
- NLGN3→NRXN1 remains a composite synapse-differentiation branch.

These are adhesion and cellular-function paths; no intracellular TF relay was
inferred.

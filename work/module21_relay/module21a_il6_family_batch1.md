# Module 21A IL-6-family relay batch 1

This first Module 21A packet curates the IL-6/gp130 intracellular relay from receptor engagement to kinase and transcription-factor branches.

## Curated relay posture

- JAK1 is retained as the dominant kinase requirement for efficient IL-6-induced gp130 phosphorylation and STAT1/STAT3 activation in the tested human cell system.
- JAK2 and TYK2 are retained as activated ancillary kinases, not as interchangeable replacements for JAK1 and not as a sequential three-kinase cascade.
- The gp130/IL6ST receptor tail is retained as the canonical docking/signaling node for STAT3 and as a separate SHP2/MAPK branch.
- SHP2/PTPN11 and MAPK1/MAPK3 are retained with branch and site context; they are not collapsed into the STAT3 edge.
- Mouse gp130 loss-of-function data support receptor-branch separation, but the source context is mammary epithelium rather than SCI.

## Boundary

This is a pre-materialization relay register. It does not create SQL `SignalingEdge` rows or claim that IL-6-family branch weights are established in injured spinal-cord astrocytes. The next pass should test LIFR/OSMR/CNTFR receptor-complex branches and then seek direct SCI or spinal-glia perturbation evidence.

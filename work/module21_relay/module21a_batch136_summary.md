# Module 21A Batch 136 review summary

Batch 136 contains 25 exact priority-8 queue rows covering Kng1/Kng2 and L1cam receptor assignments.

- 5 rows were retained as receptor-proximal relay candidates: Kng1-Plaur, L1cam-Cd9, L1cam-Cntn1, L1cam-Erbb2, and L1cam-Erbb3.
- 1 row was retained as downstream function-only: Kng2-Bdkrb2, based on Kng2 bradykinin-precursor perturbation and mouse B2-pathway physiology without direct intact-Kng2 receptor binding.
- 1 row was retained as binding-only: L1cam-Ptprz1, because the primary evidence resolves binding to the secreted phosphacan/PTPRZ1 ectodomain and does not establish full-length PTPRZ1 intracellular signaling.
- 18 rows remain explicitly unresolved, including Kng2 assignments to non-kinin receptors, Kng2 assignments to receptor complexes supported only for KNG1/HK, L1cam-Ephb2, L1cam-Fgfr2, and L1cam-ITGA4_ITGB7.
- No terminal TF was assigned; every terminal_TF value is `null` because no exact pair-matched terminal TF activation experiment was identified.

Search boundaries were recorded per row using stable PubMed query URLs and comparator primary sources. Direct KNG1/HK evidence was not transferred to Kng2 without an exact isoform assay; FGFR1, EphA, and non-alpha4beta7 integrin evidence was not transferred to the queued L1cam receptor rows. Only these two batch files were written; shared registers, Module 20A files, frozen manifest, and integration outputs were not modified.
